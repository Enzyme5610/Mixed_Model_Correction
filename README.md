# Mixed Model Correction

Web app for testing treatment effects on physiology or qPCR data with a linear
mixed model (Line and Batch as random effects, Kenward-Roger F test), with
pairwise comparisons and downloadable plots.

**App:** https://enzyme5610.github.io/Mixed_Model_Correction_KR/
